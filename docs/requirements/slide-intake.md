# Entrada de requisitos pelos slides

## Regra

Todos os slides recebidos são tratados como **fontes de requisitos e metas**, nunca como evidência de implementação ou resultado executado.

## Processo

Para cada conjunto de slides:

1. registrar disciplina, aula/sprint, professor e arquivo de origem;
2. extrair requisitos funcionais, não funcionais, de domínio, documentação e avaliação;
3. separar conteúdo obrigatório, recomendação, exemplo didático e meta quantitativa;
4. detectar conflitos com o PDF principal e com requisitos já registrados;
5. criar IDs estáveis e critérios de aceite verificáveis;
6. atualizar o roadmap somente após revisão humana;
7. manter o arquivo original fora do repositório quando houver restrição de redistribuição.
